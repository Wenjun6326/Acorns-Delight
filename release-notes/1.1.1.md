## Minor release — Acorn Jam recipe corrected, textures reduced by one pixel

A bug fix and an art tweak. No gameplay or balance changes beyond the corrected recipe.

### Fixed

* **The Acorn Jam recipe required 6 acorns instead of 4.**
  The pattern was written as:

  ```
  A . A
  A C A
  A . A
  ```

  The middle row added an acorn on either side of the cocoa bean, so a full
  **6 acorns + 1 cocoa bean** were consumed even though the documented recipe called for 4 acorns.

  It is now:

  ```
  A . A
  . C .
  A . A
  ```

  Acorns in the four corners and a single cocoa bean in the centre — exactly
  **4 acorns + 1 cocoa bean**.

### Changed

* Item textures are **one pixel smaller**, drawn on the same 16x16 canvas so the margins stay even:

  | Item | Before | After |
  | --- | --- | --- |
  | Acorn | 12 x 16 px | **11 x 15 px** |
  | Acorn Jam | 14 x 16 px | **13 x 15 px** |

* Both textures were regenerated from the original 1254x1254 artwork rather than being scaled down
  from the previous 16x16 versions, which avoids the blur of resampling twice.
* The mod icon was regenerated to match.

Both items therefore appear slightly smaller in the inventory and in hand.

### Verified

* The recipe test also asserts that the old 6-acorn layout **no longer matches**, so the recipe is
  provably narrowed rather than accidentally still accepting the old shape.
* The published jar was downloaded back and its recipe inspected: pattern `A A / C / A A`,
  4 acorn slots, 1 cocoa slot.
* `All 6 required tests passed :)` on Fabric Loader 0.18.4.

### Requirements

| --- | --- |
| Minecraft | 26.1 (also runs on 26.1.1 / 26.1.2) |
| Fabric Loader | 0.18.4 or newer |
| Fabric API | required |

Farmer's Delight, JEI and REI are all optional.

### Install

Drop the jar below into `.minecraft/mods` together with [Fabric API](https://modrinth.com/mod/fabric-api).

If you are on 1.0, note that build declares `fabricloader >=0.19.5` and will be rejected on older
loaders — use this release instead.
