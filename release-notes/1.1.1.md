## Minor release — textures reduced by one pixel

Gameplay, balance and compatibility are identical to 1.1.0. The only change is the item artwork.

### Changed

* Item textures are **one pixel smaller**, drawn on the same 16x16 canvas so the margins stay even:

  | Item | Before | After |
  | --- | --- | --- |
  | Acorn | 12 x 16 px | **11 x 15 px** |
  | Acorn Jam | 14 x 16 px | **13 x 15 px** |

* Both textures were regenerated from the original 1254x1254 artwork rather than being scaled down
  from the previous 16x16 versions, which avoids the blur of resampling twice.
* The mod icon was regenerated to match.

Both items therefore appear slightly smaller in the inventory and in hand.

### Requirements

| | |
| --- | --- |
| Minecraft | 26.1 (also runs on 26.1.1 / 26.1.2) |
| Fabric Loader | 0.18.4 or newer |
| Fabric API | required |
| Java | 25 |

Farmer's Delight, JEI and REI are all optional.

### Install

Drop the jar below into `.minecraft/mods` together with [Fabric API](https://modrinth.com/mod/fabric-api).

If you are on 1.0, note that build declares `fabricloader >=0.19.5` and will be rejected on older
loaders — use this release instead.
