## Minor release — wider loader support

Gameplay is identical to 1.0. This release only fixes compatibility, so more setups can launch the mod.

### Fixed

* **The mod refused to load on Fabric Loader below 0.19.5.**
  `fabric.mod.json` declared `fabricloader >=0.19.5`, which was far stricter than necessary, so anyone on 0.18.x or 0.19.0–0.19.4 was rejected at startup.

### Changed

* `depends.fabricloader` relaxed from `>=0.19.5` to **`>=0.18.4`**.
  That is the oldest loader available for Minecraft 26.1, and also exactly what Fabric API `0.145.1+26.1` declares (`fabricloader >=0.18.4`), so it cannot be lowered any further.
* The development environment (`loader_version` in `gradle.properties`) now also runs on **0.18.4**.
  This is deliberate: developing and testing against the minimum means that if the code ever starts relying on newer loader behaviour, the GameTests fail here instead of crashing on a player's machine.
* Added a `min_loader_version` field so `fabric.mod.json` and `gradle.properties` cannot drift apart.

### Verified

* `Loading Minecraft 26.1 with Fabric Loader 0.18.4` → all 6 GameTests pass.
* The built `acorns-delight-1.1.0.jar` was inspected and its `fabric.mod.json` confirms `fabricloader >=0.18.4`.

### Requirements

| | |
| --- | --- |
| Minecraft | 26.1 (also runs on 26.1.1 / 26.1.2) |
| Fabric Loader | **0.18.4 or newer** |
| Fabric API | required |
| Java | 25 |

Farmer's Delight, JEI and REI are all optional.

### Install

Drop the jar below into `.minecraft/mods` together with [Fabric API](https://modrinth.com/mod/fabric-api).
