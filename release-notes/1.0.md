## First playable release

> ### ⚠️ Please download 1.1.0 instead
>
> This 1.0 build declares `fabricloader >=0.19.5` in `fabric.mod.json`, which is **far stricter than
> necessary**. If your Fabric Loader is older than 0.19.5 — for example 0.18.x, or 0.19.0–0.19.4 —
> the mod will be **rejected at startup**.
>
> **[1.1.0](https://github.com/Wenjun6326/Acorns-Delight/releases/tag/1.1.0) fixes exactly this** and
> lowers the requirement to `>=0.18.4`, with identical gameplay. Unless you specifically need this
> build, use 1.1.0.

### Added

* **Acorn** (`acorn_delight:acorn`)
  * Breaking plain oak leaves has a **13% chance** to drop one.
  * Injected through Fabric's loot API as a separate pool, so vanilla's loot table is never replaced
    and the mod coexists with other mods or datapacks that touch oak leaves.
  * Weights are 13 : 87 against an empty entry; it also carries a `survives_explosion` condition so
    leaves destroyed by explosions do not drop acorns.
* **Acorn Jam** (`acorn_delight:acorn_jam`)
  * Crafted in a crafting table from **4 Acorns + 2 Cocoa Beans**.
  * Restores **4 hunger** and **3.5 saturation**, drunk like a bottle (1.6 s).
* A dedicated creative tab for the mod.
* English and Simplified Chinese localisation.

### Compatibility

* **Farmer's Delight Refabricated** — soft dependency, no conflicts.
* **JEI** — `jei_mod_plugin` entrypoint; the recipe is a standard shaped recipe and is indexed automatically.
* **REI** — `rei_client` entrypoint; same automatic indexing.

JEI and REI are optional; their entrypoints are simply not loaded when the mod is absent.

### Requirements

| | |

| Minecraft | 26.1 (also runs on 26.1.1 / 26.1.2) |
| Fabric Loader | **0.19.5 or newer** — this is the limitation fixed in 1.1.0 |

### Technical notes

* Minecraft 26.1 is the first **unobfuscated** release, so this mod is written against Mojang's
  official names; there is no `mappings` dependency and `modImplementation` / `remapJar` become
  `implementation` / `jar`.
* Toolchain: JDK 25, Gradle 9.5.1, Fabric Loom 1.17.20.
* Ships 6 in-game GameTests covering the drop rate, the recipe and the food values.

### Known issue

* The overwritten drop rate was originally 100% instead of 13%: a loot pool containing a single entry
  always drops. Caught by the GameTests and fixed by adding a weight-complementary empty entry (13 : 87).

### Install

Drop the jar below into `.minecraft/mods` together with [Fabric API](https://modrinth.com/mod/fabric-api).
