## Minor release — Acorn Jam recipe corrected

A bug fix only. The Acorn Jam recipe asked for more acorns than intended.

### Fixed

* **The recipe required 6 acorns instead of 4.**
  The pattern was written as:

  ```
  A . A
  A C A
  A . A
  ```

  The middle row added an acorn on either side of the cocoa bean, so a full
  **6 acorns + 1 cocoa bean** were consumed even though the documented recipe called for 4 acorns.

  It is now:

  ```
  A . A
  . C .
  A . A
  ```

  Acorns in the four corners and a single cocoa bean in the centre — exactly
  **4 acorns + 1 cocoa bean**.

### Verified

* The existing recipe test now also asserts that the old 6-acorn layout **no longer matches**, so the
  recipe is provably narrowed rather than accidentally still accepting the old shape.
* `All 6 required tests passed :)` on Fabric Loader 0.18.4.
